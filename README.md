# Um-l-inteligence-a-datov-anal-za
Projekt se zaměřuje na využití umělé inteligence a datové analýzy pro predikci cen nemovitostí. Pomocí dat, jako je velikost bytu, počet pokojů nebo lokalita, byl vytvořen model, který dokáže odhadnout cenu nemovitosti. Cílem je ukázat, jak lze moderní technologie využít k řešení reálných problémů v praxi.
